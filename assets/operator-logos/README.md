# Operator logos

**English** · [中文](README.zh-CN.md)

`<slug>.svg` (slugs in `crates/luyaz-web/src/oplogo.rs`). Operators without a logo show the first character of their name.
Logos are the operators' trademarks and are used only to identify the connected network. The SVGs ship with the public release; `cmlink.png` is binary and not published.

Sources (2026-09-25):
- Wikipedia / Wikimedia Commons: three-hk, csl, chunghwa, kt, skt, singtel, starhub, m1, docomo, softbank, au, smartone.
- Simple Icons (monochrome, colored with their recorded brand color): att, verizon, rakuten, t-mobile-us (Deutsche Telekom's T).
- Wikipedia: china-mobile (2019 version, also used for cmhk), china-telecom; Wikimedia Commons: lguplus.
- companieslogo.com: china-unicom, fetnet, taiwan-mobile.
- Missing: China Broadnet (only AI format online, no SVG); shows "中".
