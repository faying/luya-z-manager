## Design Context

### Users
The web dashboard (`web/`, Next.js static export served by the on-device Rust agent on `:9090`, LAN-only) is used to administer a **ZTE U60 Pro 5G CPE router** running OpenWrt. Primary user is the device owner — technically literate, comfortable with dense status data — but the UI is **also shared with other U60 owners / the community**, so it must stay approachable and not assume insider knowledge. Jobs to be done: configure Wi-Fi (incl. the new Home Mode SSID auto-off), mobile network/APN/band lock, SMS, monitoring (signal, battery, temp), and system/services. Often used on a **phone or tablet on the same LAN**, not just desktop.

### Brand Personality
Confident, utilitarian, calm. Three words: **clear, trustworthy, unfussy**. It should feel like a precise instrument panel — information-dense but never noisy. No marketing flourish; every element earns its place. Emotional goal: the user feels *in control* of their device.

### Aesthetic Direction
Deliberate system — **"Cool Tech"** (defined in `web/src/app/(panel)/admin.css`):
- **Light mode** — clean, cool, minimalist-tech.
- Cool near-white canvas (`#f6f8fb`), white cards (`#ffffff`), cool-slate neutrals, hairline borders (`#e2e8f0`), soft slate-tinted shadows. No glassmorphism/shimmer/gradients.
- **Electric-cyan accent**: deep cyan `#0e7490` (cyan-700) carries contrast — buttons (white text), links, active text — AA on white (~5:1). Bright cyan `#22d3ee` (`--admin-glow`) is for tints/focus-rings/active indicators ONLY, never as text/fills on white (it would fail contrast). Active nav = cyan-50 soft fill + a bright-cyan left rail.
- **Mobile-first**: desktop left sidebar; mobile uses a fixed **bottom tab bar** (Home / Signal / Wi-Fi / Services / More→drawer).
- Type: **Outfit** (display) + **DM Sans** (body), with PingFang/Source Han CJK fallbacks; tabular numerals for status/metrics.
- Tokens live under `.admin-theme` as CSS variables (`--ds-*`, `--admin-*`) and are exposed as Tailwind utilities (`bg-bg-card`, `text-accent`, `font-display`, `text-text-dim`, etc.).
- **Anti-references**: the "AI slop" look — cyan-on-dark, purple→blue gradients, neon glows, gradient text, glassmorphism, identical icon+heading+text card grids, hero-metric layouts.

### Design Principles
1. **Tokens, never hard-codes.** All color/spacing/radius/shadow come from the `.admin-theme` variables or their Tailwind utilities. A raw hex or arbitrary `[#xxxxxx]` is a defect.
2. **Information density with rhythm.** Dense status data is fine, but group it with varied spacing and hairline separators — not walls of identical cards.
3. **Mobile is a real target.** Layouts must work on a phone on the LAN: no horizontal scroll, ≥44px touch targets, controls reachable one-handed. Adapt, don't amputate.
4. **WCAG AA is the floor.** ≥4.5:1 text contrast, labelled controls, visible focus, keyboard operability, semantic structure.
5. **Quiet confidence.** Restraint over decoration; deep cyan used sparingly as the single accent (bright cyan only for glow/active hints); status conveyed by the typographic `.admin-status` dot-label, not loud pills.
