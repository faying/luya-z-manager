# 设计：触屏菜单按「我想做什么」重排（5 个标签）

2026-09-25 · /office-hours · Status: 已实现（本地提交，未上机）
仓库：source/touch-ui（触屏）+ source/manager（agent / 网页）

## 问题

用户原话：「层级与结构混乱」「感觉每个地方都能点击，但点击效果都不像我想要的」「锁频段、切网络、Tailscale 等网络相关功能的分类乱七八糟」；另外「APN 选择在设备端没有办法选」「现在到底在用哪个也看不出来」。

现状（src/ui.c 梳理，9-25）：
- 4 个标签「首页 / 图表 / 功能 / 系统」+ 14 个二级页。
- 一个功能多个入口：CHILL（首页磁贴、首页 CHILL 卡、功能磁贴、情景页出口弹层）、Tailscale（首页出口行、首页 TS 卡）、告警（状态栏 ▲、系统「健康」）、已连设备（Wi-Fi 页、情景·网络页）、网速单位（点状态栏、系统开关）。
- 名不副实：「锁频」页里是网络模式；功能磁贴「网络」点进去标题是「情景 · 网络」，里面混着情景、出口 IP、运营商、手动选网、邻区、设备流量 6 件事。
- 小区信息页说「邻区本机未提供」，情景·网络页却有「邻小区 扫描」。
- 首页「载波 ›」只在本页滚动，不开新页；「流量」行和可点的行排在一起却点不动。
- 二级页只能点「‹」返回，不能滑；再次打开不回到顶部。
- 没有 APN。

## 前提（用户 9-25 全部同意）

1. 触屏 = 随身看状态 + 快速切换；网页 = 填写和管理。自定义 APN（要打字）、访客 Wi-Fi 只在网页；触屏看得到在用哪个 APN、能在已有 APN 间切换。
2. 按「我想做什么」分类，每个功能只有一个家，首页只放结论、情景和各类摘要。
3. 全机一套点击规则（见下）。
4. 原厂带宽分配 6 模式不做（见「不做」）。
5. 只动结构和交互，不动视觉（DESIGN.md 的颜色、字体、卡片不变）；已有功能一个不删，只搬家、合并入口。

## 情景是独立模块（用户 9-25）

情景和蜂窝网络本身无关：它只联动 Wi-Fi、CHILL、Tailscale 这类「在哪、怎么用」的东西，不碰网络模式、锁频、运营商、APN。
- 情景页只放：情景列表（自动 + 各情景，单选两下确认）、每个情景会做什么（开关 Wi-Fi / CHILL 档位与出口 / Tailscale）、国外时的「CHILL 出口」弹层。
- 原情景·网络页里的出口 IP、运营商、手动选网、邻区、设备流量全部搬走（见上表），情景页里不再出现任何蜂窝网络内容。
- 以后情景要联动的新东西也只在 Wi-Fi / 出口 / 系统范围内加；情景引擎（agent 侧）不加对网络模式、APN、锁频的写操作。

## 点击规则（全机统一，写进 DESIGN.md §4）

- **›** = 打开一页（或跳到一个标签）。没有 › 的行不可点、没有按下态。
- **开关** = 立即生效。例外：可能把自己断开的（Wi-Fi 总开关、2.4G/5G 关掉当前连接的那个频段）改成两下确认。
- **单选列表**（情景、APN、eSIM、网络模式、运营商、CHILL 出口/档位、测速服务器）统一一个组件：左边单选圈；会断网的，第一下整行变色 + 写出后果，4 秒内再点才执行；执行后「切换中…」直到读回结果；点已生效项说一句「已经是…」。
- **按钮** 只用于一次性动作（测速、搜索网络、全部已读、恢复默认）。
- **返回**：点「‹」或从左边缘（x < 24）右滑；二级页打开时标签栏隐藏。
- 每次打开二级页都回到顶部；从首页摘要跳标签也回到顶部。
- 页面标题 = 入口上的文字。

## APN（新）

触屏「蜂窝 → APN」：
- 顶部一句：「正在用：China Telecom（ctiot · IPv4v6）· 自动选择」。
- 单选列表：「自动（按 SIM 识别）」+ 手动 APN 各一行；选中即 两下确认 → 切换中 → 读回。
- 底部灰字：「新建或修改 APN 请用网页管理」。
- 写入走 zte-agent 已有接口（网页在用的 `/api/router/apn/profiles/activate`、apn_mode），不在触屏里直接调 ubus。

固件接口（`zwrt_apn_object`，9-25 读过）：`get_apn_mode`（0 = 自动）、`getAutoApnList`、`getManuApnList`、`get_enabled_manu_apn_id`、`set_apn_mode`、`enable_manu_apn_id`。
**注意**：手动列表里的 `isEnable=true` 只表示「手动模式下选中的那条」，自动模式时它并不在用。

网页修正：APN 页「使用中」只标真正在拨号的那条；手动列表里被选中但当前是自动模式时，写「手动模式时用这条」。

## 不做

- **原厂带宽分配 6 模式**（`zte_smart_mng_set_qos_mode`：Ai / Live / Chat / Game / Video / Nomal）：只在多台设备把带宽占满时决定谁先走；除「极速」外都要 xdpi 识别应用（`zte_smart_manage` 里模式按 xdpi 识别结果分配），而 xdpi 9-23 为省约 25% CPU 已关；特征库以国内应用为主。用户 9-25 同意不做。网页 QoS 页现在调用固件没有的方法、一直坏着：改成只读显示「极速（不区分应用）」和一句原因。
- 访客 Wi-Fi：网页已有 `/router/wifi-guest`，触屏不做。
- 方案 A（只新建蜂窝页、保留磁贴墙）：磁贴墙一多又乱。方案 B（功能页改分类列表、三层）：多点一层，还要页面栈。
