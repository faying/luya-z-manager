# 支援矩阵：哪些真的验证过

[English](SUPPORT-MATRIX.md) · **中文**

快照：2026-10-24。这张表只记在真设备上亲眼看到能用的东西。编译通过、离线测试通过、或者一台机器上的结果，都不外推到别的机器、固件或型号。

- **已验证**：在这一行的真设备上看到能用（附日期）。
- **仅设计**：有代码，但只用 mock 或离线测过。
- **未知**：没有证据，或证据互相矛盾。

## 行

| 行 | 硬件 | 固件 |
|---|---|---|
| A | MU5250，单卡槽 | 国内版 `B31`，从 `B27` 升级（另一个 A/B 槽还留着 B27） |
| B | MU5250，双卡（`support_dual_sim=1`） | 国内版 `B31`，出厂即是、从没升级 |
| 其他固件 | MU5250 | `B27`（历史）、`B28`–`B30`、其他地区版本 |
| MU5252 | MU5252 | 任意 |

两台报告的固件版本字符串相同，可写设置也相同（只读对比，2026-10-22）。B31 上的结果不适用于 B28–B30，要分别验证。

## 已知缺口

- B28–B30 和其他地区固件从没测过。装机包不会拒绝它们，但上表不适用。
- 「B28 起删了 ADB」的说法未证实：B31 上 `adbd` 还在，变的是一个 USB 设置方法。
- B31 上从飞行模式（低功耗模式）恢复的情况未知，故意不测：目前见过的唯一出路是重启。

如果你有表里「未知」那几行的设备，想帮忙，请开 issue，附上固件版本字符串（原厂网页「设置 → 关于」）和装机包只读命令 `status`、`doctor` 的输出。贴之前请删掉 IMEI、ICCID 和手机号。
